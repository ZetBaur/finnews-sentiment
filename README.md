# Классификация тональности финансовых новостей

Учебный проект: по короткой финансовой фразе определить тональность (positive / negative / neutral).

## Данные

Financial PhraseBank, файл `Sentences_50Agree.txt` (формат `текст@класс`, кодировка latin-1). Загрузка: `load_data.py`.

## День 1. Первичный анализ (`eda.py`)

Результаты запуска:

- Размер: 4846 строк, 2 колонки (`text`, `sentiment`), обе строковые.
- Пропусков нет (0 в обеих колонках).
- Классы: neutral 2879 (59,4%), positive 1363 (28,1%), negative 604 (12,5%).
- Дубликаты текстов: 8 (около 0,2%).
- Длина текста: в среднем 128 символов (23 слова), медиана 119 символов (21 слово), минимум 9 символов (2 слова), максимум 315 символов (81 слово).

Наблюдения:

1. Классы несбалансированы: нейтральных почти в 5 раз больше, чем негативных. Значит, accuracy (доля верных ответов) будет обманчивой: модель, которая всегда отвечает neutral, получит около 59%. Нужны precision, recall, F1 по каждому классу.
2. Пропусков нет, чистить пустые тексты не нужно.
3. Тексты короткие (одно предложение), разброс длины умеренный. Обрезать или отбрасывать длинные не требуется.
4. В примерах знаки препинания отделены пробелами (`company 's`, `, `, `20 % -40 %`). Похоже, тексты уже разбиты на токены.
5. Часть примеров спорная: класс не всегда очевиден по тексту (например, фраза про индекс FTSE в классе negative). Версия файла `50Agree` включает фразы, где разметчики согласились лишь на 50%.

Решение: 8 дубликатов удалить на этапе очистки (день 2), чтобы одна фраза не попала и в обучение, и в тест. Не проверено: совпадают ли классы у дубликатов; графики не построены.
